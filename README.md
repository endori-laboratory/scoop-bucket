# Endori's Scoop Bucket

[![update](https://github.com/endori-laboratory/scoop-bucket/actions/workflows/update.yml/badge.svg)](https://github.com/endori-laboratory/scoop-bucket/actions/workflows/update.yml)

A scoop bucket containing useful apps that are not in the main bucket.

[Scoop](https://scoop.sh/) is a windows package manager similar to apt-get or homebrew.
You can add this bucket to scoop using

```
scoop bucket add endori https://github.com/endori-laboratory/scoop-bucket
```

Special thanks to [@ScoopInstaller](https://github.com/ScoopInstaller) for manifest.json template and excavator actions!
